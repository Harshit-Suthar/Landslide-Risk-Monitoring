================================================================================
NER Landslide Early Warning & Risk Monitoring System
Complete Beginner-Friendly System Guide: Features, Workflows, APIs & Setup
================================================================================

1. WHAT IS THIS PROJECT IN SIMPLE WORDS?
--------------------------------------------------------------------------------
In the hilly North Eastern States of India (such as Meghalaya, Assam, Mizoram, 
Nagaland, Arunachal Pradesh, Sikkim, Manipur, and Tripura), heavy monsoon rains 
frequently trigger dangerous landslides and road blockages. 

This platform is a smart early warning web system. It combines satellite imagery, 
ground moisture sensors, and Artificial Intelligence (AI) to predict landslides 
before they happen and immediately warn people so they can safely evacuate in time.

Key Features:
- Citizen Incident Reporting: Take a photo of a crack or landslide, tag GPS, and send to authorities.
- Officer Verification: Control room staff review photos and click Verify or Reject.
- Smart AI Risk Prediction: Checks rainfall, soil wetness, slope angle, and past history.
- Emergency Pop-Up Alert Box: Red alert box pops up on screen with instructions and direct 1070 helpline call.
- Public Live GIS Map & Radar: Anyone can view live hazard pins and 7-day weather forecasts without signing in.


2. HOW THE COMPLETE SYSTEM WORKS (END-TO-END WORKFLOW)
--------------------------------------------------------------------------------
Step 1: Rain & Ground Sensors measure soil saturation every 15 minutes.
Step 2: Citizens spot danger and submit reports with photos and GPS.
Step 3: Incident is saved in database with status 'Pending'.
Step 4: Emergency control room officers review and click 'Verify'.
Step 5: AI calculates the landslide risk level: Low, Medium, High, or Critical.
Step 6: Emergency Pop-Up Alert Box, SMS, and warnings are dispatched to the public.
Step 7: Live GIS Map updates with danger pins and evacuation shelter routes.


3. GUIDE TO ALL PAGES ON THE WEBSITE
--------------------------------------------------------------------------------
A. Public Pages (No Login Required):
- Home Page (/): Live alert marquee, sensor counters, 8-state hazard index, interactive map preview, live weather widget, and interactive AI risk simulator.
- Live GIS Risk Map (/map): Full-screen map with Critical, High, Medium, Low pins, search, and district filters.
- Weather Radar (/weather): 24h rain gauges for all 8 state capitals, soil wetness ratio, and 7-day forecast.
- Emergency Alerts Bulletin (/alerts): Noticeboard for Red/Orange/Yellow warnings with 1-click Pop-Up Alert triggers.
- Safety & Evacuation Guide (/safety): 6 early warning indicators, 3-step action guide, and interactive 72-hour Go-Bag checklist.
- About the System (/about): Sensor network explainer (piezometers, inclinometers, radar, satellites) and partners.

B. Citizen Portal:
- Citizen Report (/citizen/report): Submit photos, GPS, and severity of new incidents.
- My Reports (/citizen/my-reports): Track submitted reports.
- Citizen Map (/citizen/map): District-specific hazard map.

C. Admin Console:
- Dashboard (/admin/dashboard): Active alerts, reports today, and operational live map.
- AI Model Console (/admin/ai-model): Live Prediction Workbench to test slope locations against the Python AI service.
- Reports (/admin/reports): Review and verify public submissions.
- Users (/admin/users): Manage officers and field staff.


4. TECHNOLOGY STACK
--------------------------------------------------------------------------------
- Frontend: React + Vite + Tailwind CSS (Fast, responsive website)
- Maps: Leaflet + OpenStreetMap (Live interactive GIS mapping)
- Backend API: Node.js + Express (Handles requests, notifications, and weather on port 5000)
- AI / Machine Learning: Python + FastAPI (Hazard calculation engine on port 8000)
- Database & Storage: Supabase PostgreSQL (Stores users, locations, reports, and media)


5. APIS USED IN THE SYSTEM
--------------------------------------------------------------------------------
- GET /api/health : Server health check.
- GET /api/weather/:district : Live rainfall (mm) and 7-day forecast.
- POST /api/predict : Public endpoint calculating risk via the Python AI engine.
- POST /api/admin/ai-model/predict : Admin endpoint for detailed AI predictions with confidence.
- GET /api/admin/dashboard/stats : Aggregates active alert and report counts.
- PATCH /api/admin/reports/:id/verify : Approves or rejects citizen reports.
- POST /api/alerts/send : Broadcasts emergency alerts to district residents.
- POST http://127.0.0.1:8000/predict : Python FastAPI geotechnical inference engine.


6. DATABASE STRUCTURE (SUPABASE)
--------------------------------------------------------------------------------
- public.users: User accounts (Admin, District Officer, Field Agent, Citizen).
- public.locations: Monitored landslide spots across 8 NE States.
- public.reports: Incident reports with photos, GPS, and status (Pending/Verified/Rejected).
- incident-media: Cloud storage bucket for photo and video uploads (up to 50MB).

Note: The full database setup SQL script is located in supabase_schema.sql.


7. HOW TO RUN THE APP LOCALLY
--------------------------------------------------------------------------------
From Project Root:
  npm run dev          -> Starts website at http://localhost:5173

Starting individual services:
  Backend:   cd backend && node server.js                     -> http://localhost:5000
  AI Engine: cd ml-services && python -m uvicorn app.main:app --port 8000 -> http://localhost:8000
  Frontend:  cd frontend && npm run dev                       -> http://localhost:5173
